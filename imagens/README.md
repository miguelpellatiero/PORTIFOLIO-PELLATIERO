# Pasta de Imagens do Portfólio

Coloque suas imagens de projetos nesta pasta com os seguintes nomes:

## Imagens esperadas:

1. **marca-essencia.jpg** - Projeto de Design/Identidade Visual
2. **manifesto-urbano.jpg** - Projeto de Vídeo/Institucional
3. **campanha-inverno.jpg** - Projeto de Publicidade/Campanha
4. **revista-forma.jpg** - Projeto de Design/Editorial
5. **motion-branding.jpg** - Projeto de Vídeo/Motion Graphics

## Instruções:

- Coloque as imagens nesta pasta (imagens/)
- As imagens devem ter os nomes exatamente como listados acima
- Formatos recomendados: JPG, PNG (JPG é melhor para portfólios)
- Tamanho recomendado: 1200x800px (proporção 3:2) para melhor qualidade

## Exemplo de estrutura:

```
PORT-MIGUEL/
├── index.html
├── style.css
├── script.js
└── imagens/
    ├── marca-essencia.jpg
    ├── manifesto-urbano.jpg
    ├── campanha-inverno.jpg
    ├── revista-forma.jpg
    └── motion-branding.jpg
```

As imagens já estão configuradas no HTML com `background-image: url('imagens/nome-da-imagem.jpg')`

Basta adicionar seus arquivos aqui que tudo funcionará automaticamente!
